01 / Motivation

Why polynomial interactions?

Affine projections combine state channels additively. Physical response often depends on their products. PRISM retains the linear path and adds compact products between learned projections.

02 / Method

PRISM learns polynomial state interactions.

A first-order factor is enriched with products of additional learned factors. The resulting polynomial state enters the unchanged policy.

Deployable input Proprioceptive input
jointsvelocitiesgripperhistory

PRISM Linear state + learned interactions
Linear term preserve first-order response

Interaction term multiply learned factors
polynomial state representation
→
Policy input Conditioned state consumed by the same downstream policy
Compact: factorized instead of enumerating every pair. Deployable: no extra sensing or dynamics labels. Drop-in: policy and action interface stay unchanged.

Takeaway

Richer state. Same interface.
